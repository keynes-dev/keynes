# Security

Report suspected vulnerabilities privately to Shubhankar Sharan at
[shub@shub.gg](mailto:shub@shub.gg). Do not open a public issue with exploit
details or credentials.

Include the affected commit or package version, a minimal reproduction, expected
impact and relevant environment details. Remove secrets and personal data. We
will discuss a fix and disclosure with you before publishing details.

## Supported versions

Keynes packages are not yet published. Security fixes currently target the
default branch; there are no supported registry releases or promised backports.
Node.js 24+ is required for development. This does not imply every Node/OS
combination has been release-qualified.
