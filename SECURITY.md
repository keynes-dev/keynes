# Security

Report suspected vulnerabilities privately to Shubhankar Sharan at
[shub@shub.gg](mailto:shub@shub.gg).

Include the affected commit or package version, a minimal reproduction, expected
impact and relevant environment details. Remove secrets and personal data. We
will discuss a fix and disclosure with you before publishing details.

## Supported versions

Security fixes target the default branch while packages are unpublished. Use the
latest source revision when reporting or verifying a fix.
