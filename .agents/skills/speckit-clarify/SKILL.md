# Clarify the selected feature

Resolve the active identity and read spec.md, relevant product contracts, and
the code or documents that can answer discoverable questions.

Ask only about material scope, behavior, compatibility, constraints, or acceptance
choices. Use existing user decisions and authorization. Do not reopen settled
choices or ask for facts available in the repository.

Update the same specification. Record a concise Clarifications section when
needed. Update the story, requirements, scenarios, and success criteria together
when an answer changes intent. Keep implementation design in plan.md.

Preserve one independently acceptable outcome and exact Linear identity.
Identify additional peer feature work when scope grows; do not create phase
sub-issues or copy tasks/evidence into Linear. Recheck the requirements checklist
and report readiness for planning.
