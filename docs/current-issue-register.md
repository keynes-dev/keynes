## Status rules

Each row uses one status:

- **Confirmed** means the current witness reproduces the issue or gap.
- **Rejected** means the current witness disproves the source claim.
- **Superseded** means the source claim was valid or relevant in its original
  context, but the triggering state is absent from current `main`.
- **Inconclusive** means the available witness cannot decide the claim.

The proposed owner names a work category, not an allocated feature. The roadmap
phase decides feature ownership after the domain decision.

## Phase 4 decision disposition

The accepted [product contract](product.md) and
[runtime architecture](architecture.md) resolve the issue register's domain
dependencies without claiming that current code is repaired:

- IR-002 resolves to reference-only loading with generated Resource and Policy
  catalogs; PostgreSQL returns operational Budget state.
- IR-003 and IR-004 resolve architecturally to one coherent inspection snapshot
  and independent repeatable internal history cursors.
- IR-009 and IR-010 resolve to independent Resource definitions, quantity-free
  bindings, Budget-owned quantity, and valid zero-funded Budgets.
- IR-011 resolves to Promise rejection for public asynchronous failures, with
  runtime admission before input validation.
- IR-012 resolves to one immutable `embedded` or `remote` installation
  profile, with no public IAM surface.
- IR-013 resolves to Policy-name-discriminated heterogeneous lineage history.
- IR-015 resolves under the explicit greenfield compatibility decision: unused
  public concepts may be removed instead of preserved.
- IR-022 resolves to one `node >=24` package range. Production guidance
  requires an upstream-supported Node.js release, and package qualification
  tests the minimum and latest release lines.

No unresolved product or accounting choice remains before roadmap allocation.
The issues stay confirmed until an owning implementation or documentation
feature changes the affected current state and exact-revision evidence verifies
the result.
