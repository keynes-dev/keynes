# FEAT-0013 decision disposition

**Status**: Retained historical planning record; current scope comes from the deployment-mode roadmap
**Date**: 2026-09-02
**Normative owners**: [product](../../product.md), [architecture](../../architecture.md), [ADR-0007](../../adr/0007-direct-postgresql-remote-access.md), [specification](spec.md), and the design contracts in this directory

This file preserves the disposition of the 16 design topics reviewed before planning. It is an index, not a second contract. When this summary conflicts with a normative owner, update or follow the normative owner.

## Scope count

For this count, a decision is branch-scoped when it changes only the direct remote access path. On that repository-reach axis, six decisions are branch-scoped: authority address, TLS, remote operation recovery, remote Budget references, retry behavior, and internal history paging that preserves `inspect()`.

Ten decisions extend beyond this branch: SDK initialization, deployment parity, contract ownership, HTTP removal and Cloud retirement, compatibility, authentication infrastructure, limit taxonomy, public errors, evidence lanes, and Resource binding. [FEAT-0014](../0014-resource-bound-budget/spec.md) delivers decisions 2 and 16 as Resource-bound Budget creation. The other cross-feature decisions change shared repository contracts or later deployment work even when FEAT-0013 performs their first implementation.

Delivery ownership is a separate question. FEAT-0013 implements decisions 1, 5, 7 through 12, and the remote portions of 6, 13, and 14. Later features consume several of those durable results.
