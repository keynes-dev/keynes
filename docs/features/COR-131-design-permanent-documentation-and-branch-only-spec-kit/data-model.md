# Documentation and delivery records

These are Markdown review records, not a database or metadata service. Their owning documents define the fields and rules:

- [Topic owner](contracts/documentation-ownership.md): a behavior or rationale and its single permanent documentation owner.
- [Migration entry](migration-map.md#coverage-protocol-before-removing-a-directory): source content, destination or retirement reason, and verification required before removal.
- [Delivery record](contracts/delivery-retention.md#ordered-feature-closeout): issue identity, verified revisions, evidence, historical links and closeout sequence.
- [Work proposal](work-proposals.md): a bounded outcome with inputs, outputs, prerequisites and acceptance.
