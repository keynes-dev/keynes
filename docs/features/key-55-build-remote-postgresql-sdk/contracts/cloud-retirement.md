# Private Cloud service retirement contract

`apps/cloud` remains active until direct PostgreSQL coverage owns each assertion that is still required. Historical KEY-47 documents and retained evidence never change.

Before deletion, inventory every Cloud edge in workspace discovery, generation, root commands, structural checks, package dependencies, tests, documentation, and workflows. Classify each edge as:

- replaced by a named SDK or PostgreSQL test;
- obsolete because it tests the rejected HTTP data path; or
- deferred to a later self-hosted or managed feature.

The replacement map must cover authenticated tenant isolation, procedure allowlisting, replay and conflict behavior, response loss, reconnect after process loss, database unavailability, safe errors, and any shared Budget assertions not already owned elsewhere.

Delete the active service only after the map has no unexplained edge and the replacement tests pass at the same revision. Remove its generation, unit, system, workspace, root-script, and repository-layout references in the same change. Do not delete historical feature artifacts or rewrite old evidence as proof of the direct PostgreSQL path.

The bearer-token authentication, HTTP request and response envelopes, service listener, service process restart, route allowlist, and HTTP status projection are obsolete because ADR-0007 rejects the HTTP Budget data path. PostgreSQL role authentication, generated procedure dispatch, pool lifecycle, validation, error safety, replay, and recovery all have named replacement owners above. Self-hosted packaging, managed operation, positive TLS deployment profiles, backup recovery, and production readiness remain later evidence lanes; deleting the service does not claim them.

At the Phase 5 accepted revision, all named replacement owners passed together in the 202-scenario PostgreSQL 18.6 record and the 341-test SDK lane, clearing the implementation prerequisite for T046. The Phase 6 deletion revision `52da617be4f77ef5913955e397c3bc6ff2423ae6` then passed the same 341-test SDK lane and an expanded 203-scenario PostgreSQL 18.6 record, including denied cross-tenant reads and mutations with unchanged owner state. This exact-revision evidence accepts the active-path deletion without treating the earlier Phase 5 result as evidence for later source.
